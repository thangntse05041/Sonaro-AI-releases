# Sonaro AI

無料のAIとチャット、出典付きのWeb検索、ドキュメントやコードの作業 — パソコンでもスマホでも。

**ウェブサイト:** https://sonaroai.app/ja/about

このリポジトリはインストーラーのみを公開しています。ソースコードは別で管理しています。

## 主な機能

- アカウント不要ですぐ使える無料の AI。パソコン上の AI や自分の API キーも利用可能。
- 出典付きの Web 検索、各主張を検証するディープリサーチ。
- PDF、Word、Excel、画像、音声、動画の読み取り。Word、PowerPoint、Excel ファイルの作成。
- 会話の中で画像、読み上げ、音楽、動画を作成。
- 指示とツールを持つアシスタント、資料フォルダーから作るナレッジベース（パソコン）。
- Code（パソコン）：承認モードに従って AI がファイルの読み書きとコマンド実行を行い、サブ AI が並行して作業。
- Google でサインインすると複数端末で同期。内容はデバイスを出る前に暗号化。

## インストール

- アプリはまだコード署名されていません。**Windows:** SmartScreen の警告が出たら **詳細情報 → 実行** を押します。
- **macOS:** 初回はアプリを右クリック → **開く**、またはシステム設定 → プライバシーとセキュリティ → **このまま開く**。
- **Android:** ダウンロードした `.apk` を開きます。確認されたら提供元不明のアプリのインストールを許可します。
- 無料のAIはすぐに使えます。パソコンでAIを動かす場合は [Ollama](https://ollama.com/download) をインストールするか、アプリ内でインストールしてモデルをダウンロードします（設定 → Ollama）。
