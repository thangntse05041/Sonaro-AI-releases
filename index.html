Có gì trong app

  • AI miễn phí dùng ngay, không cần đăng nhập hay API key.
  • Tuỳ chọn: AI chạy trên máy qua Ollama, hoặc OpenAI, Claude, Gemini, OpenRouter, OpenCode Go và dịch vụ kiểu OpenAI bằng API key của bạn.
  • AI tự tìm web khi cần và trả lời kèm nguồn [1], [2].
  • Đính kèm ảnh và tài liệu (PDF, Word, Excel, CSV…); AI tạo file Word, Excel, Markdown để tải về.
  • Code (máy tính): AI đọc, sửa file, chạy lệnh và test trong thư mục bạn chọn, theo chế độ duyệt; mở trang web đang phát triển để tìm lỗi, bạn xem trực tiếp.
  • Connectors (MCP), skills, lịch chạy, nói để gửi và đọc to câu trả lời.
  • Đăng nhập Google để đồng bộ trò chuyện giữa máy tính và điện thoại, và điều khiển máy tính từ điện thoại.
  • Giao diện tiếng Việt, English, 日本語; sáng/tối.

Cài đặt

  • App chưa được ký số. Windows: nếu SmartScreen cảnh báo, bấm More info → Run anyway.
  • macOS: lần đầu mở, nhấp chuột phải vào app → Open, hoặc System Settings → Privacy & Security → Open Anyway.
  • Android: mở file .apk đã tải; nếu được hỏi, cho phép cài ứng dụng không rõ nguồn gốc.
  • Muốn chạy AI trên máy: cài Ollama, hoặc cài và tải model ngay trong app (Cài đặt → Model trên máy).

Cập nhật

  • Windows: app tự tải bản mới và cài khi bạn bấm cập nhật.
  • macOS: app báo khi có bản mới và mở trang tải; cài file .dmg mới đè lên bản cũ.
  • Android: app tải bản mới ngay trong app rồi mở trình cài; dữ liệu được giữ nguyên.
