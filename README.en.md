# Sonaro AI

Chat with free AI, search the web with cited sources, work with documents and code — on your computer and phone.

**Website:** https://sonaroai.app/en/about

This repository only hosts the installers; the source code is kept separately.

## Main features

- Free AI that works right away without an account; or AI on your computer, or your own API key.
- Web search with cited sources; deep research that checks each claim.
- Reads PDF, Word, Excel, pictures, audio and video; makes Word, PowerPoint and Excel files.
- Makes pictures, speech, music and video right in the conversation.
- Assistants with their own instructions and tools; a knowledge base from document folders (computer).
- Code (computer): the AI reads and edits files and runs commands under an approval mode, with helper AIs working in parallel.
- Sync across devices after signing in with Google; content is encrypted before it leaves the device.

## Install

- The app is not code-signed yet. **Windows:** if SmartScreen warns, click **More info → Run anyway**.
- **macOS:** the first time, right-click the app → **Open**, or System Settings → Privacy & Security → **Open Anyway**.
- **Android:** open the downloaded `.apk`; if asked, allow installing unknown apps.
- The free AI works right away. To run AI on your computer: install [Ollama](https://ollama.com/download), or install it and download models in the app (Settings → Ollama).
