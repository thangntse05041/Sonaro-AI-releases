# Sonaro AI

Chat with free AI, search the web with cited sources, work with documents and code — on your computer and phone.

**Website:** https://sonaroai.app/en/about

This repository only hosts the installers; the source code is kept separately.

## Install

- The app is not code-signed yet. **Windows:** if SmartScreen warns, click **More info → Run anyway**.
- **macOS:** the first time, right-click the app → **Open**, or System Settings → Privacy & Security → **Open Anyway**.
- **Android:** open the downloaded `.apk`; if asked, allow installing unknown apps.
- The free AI works right away. To run AI on your computer: install [Ollama](https://ollama.com/download), or install it and download models in the app (Settings → Local models).
